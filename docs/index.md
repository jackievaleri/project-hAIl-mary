## Why this project exists

To find **underrated fantasy football draft picks** — players whose expected
production is meaningfully higher than the draft cost the consensus assigns
them.

Everyone in the league drafts off the same rankings. The edge is in the
players those rankings get wrong, so this project measures projected value
against average draft position (ADP) and turns the biggest gaps into a
round-by-round target list.
